@AGENTS.md

Read the repository-wide rules in `AGENTS.md` before doing any work. Also read the
nested `AGENTS.md` of your target module, the assigned GitHub Issue, and the
interface specification in `docs/contracts/INTERFACES.md`.

interfaces affected, tests, and whether the change is confined to the target
module. The root rules are the source of truth; do not maintain conflicting
Claude-only architecture or scientific instructions.
