1 Lead + 3 Developers

项目负责人 / Research & Product Lead

定义研究目标和 MVP 范围；负责 Agent 核心算法、实验协议、跨模块架构决策及最终成果验收。无需参与日常代码审查。

科研核心

模块协作与交付关系

先固定最少量公共契约，其余内部设计由各负责人决定。

A · 推荐模型与数据→B · 遗忘与静态评测→C · 平台集成与展示

你的 Agent 算法独立接入 C 搭建的 Simulation Runner；A 提供模型打分与推荐能力；B 提供遗忘后模型及评测记录。

适配 Claude Code / Codex 的工作流

不要求负责人读源码，但必须由模块开发者为实现和实验正确性负责。
